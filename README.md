# Engineering Automation Toolkit

A collection of Python scripts and utilities developed to automate repetitive engineering tasks, process technical data, and simplify day-to-day workflows.

The repository contains small, task-oriented tools built around practical engineering requirements, with a focus on data processing, Excel automation, and engineering drawing utilities.

## Projects

The repository is organized into individual folders, with each folder containing a separate tool or automation project.

Some of the included utilities cover:

- **CSV Data Processing** – Converting and reorganizing engineering data between different formats.
- **Excel Automation** – Automating repetitive spreadsheet operations and data handling using Python.
- **ISAMI Workflow Automation** – Supporting selected input-file and data-management tasks.
- **Engineering Drawing Processing** – Detecting drawing annotations and extracting relevant information using computer vision and OCR.

Refer to the README inside each project folder for its functionality, requirements, configuration, and usage instructions.

## Technologies

- Python
- OpenCV
- Tesseract OCR
- xlwings
- CSV and Excel data processing

Individual projects may require additional dependencies.
